# Keycard and Shell Integration

Privacy Pools V1 research uses existing Keycard capabilities,
including Keycard 4.x BIP-85 derivation, together with
experimental Keycard Shell firmware changes.

It is not a standalone Privacy Pools JavaCard applet.

Research integration:
https://github.com/keycard-tech/keycard-shell/pull/234

Source attribution, build compatibility, and deployment safety
must be checked before publishing additional firmware files.
